# Solve_Square
## Краткое описание
Это программа, созданная для решения квадратных уравнений. В ней есть 10 тестов, поверяющих, правильно работает программа, или нет.
Запуск тестов можно осуществить из программы и из стороннего файла.
Сама программа работает с рациональными числами.
При неправильном вводе коэффициентов программа сама предложит повторить попытку.
## Как пользоваться
Как запустить и правильно работать с программой:	
1) открыть файл "Square_main.exe"

2) В открывшемся окне нужно выбрать: хотите вы проводить тест программы или нет(введите "yes" если хотите и "no" если не хотите).
<img width="1079" height="599" alt="image" src="https://github.com/user-attachments/assets/d5d552de-77a2-4c8b-b8e0-28da32bb74c1" />

2.1) Если вы ввели "yes", то далее вам нужно выбрать то, откуда программа будет брать данные для тестов 
		(введите "program" если из программы и "file" если из отдельного файла "Square_test_file.txt").
<img width="1081" height="600" alt="image" src="https://github.com/user-attachments/assets/17499a6c-e7d1-4529-8558-18b6b51d574f" />
	
2.2) Программа проведет тесты и выведет количество успешно пройденных, если не все тесты прошли(это вина разраба, сорри), то в консоли будет напечатано, какие тесты провалились.
<img width="1082" height="597" alt="image" src="https://github.com/user-attachments/assets/bf515e59-16c4-437c-b71c-a39d4a9899c8" />

3) после успешной проверки (или если вы написали "no" в пункте 2) программа предложит ввести три коэффициента(соответственно a b c из стандартного вида квадратного уравнения ax^2 + bx + c = 0)
	Важное уточнение: нужно вводить только коэффициенты через пробел (Пример: 1 9 8).
<img width="1080" height="603" alt="image" src="https://github.com/user-attachments/assets/8377f68f-7bd7-4cb5-ab2f-8f00ad60dc64" />

5) Далее, о чудо, вы увидите количество корней и соответственно сами корни, с картинкой, подтверждающей, что все прошло успешно.
<img width="1077" height="599" alt="image" src="https://github.com/user-attachments/assets/4892a775-34b8-4f37-b5cd-297f549a6037" />

6) После, будет предложено продолжить решать уравнения(соответственно ввести "yes" или "no")
6.1) При вводе "yes" все будет так же как и в пункте 3
<img width="1081" height="599" alt="image" src="https://github.com/user-attachments/assets/07344ef0-31c0-4b8a-b65e-001e095f1539" />

6.2) При вводе "no", программа заверши работу, то же самое будет происходить если вы будете вводить неправильные символы, кроме ввода коэффициентов, там программа предложит ввести их заново
